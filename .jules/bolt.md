## 2025-05-18 - [Route-level Code Splitting for Heavy Rive Dependencies]
**Learning:** The `@rive-app/react-webgl2` library and dynamic Rive wheelspin engine account for over half of the application's JavaScript payload (~303 kB minified out of ~586 kB). By lazy-loading the `/wheelspin` route component with `React.lazy` and `React.Suspense`, the initial bundle size for the main landing page is reduced from 586 kB down to 282 kB (~52% size reduction), dramatically improving FCP and LCP for first-time visitors who enter through the portfolio home page.
**Action:** When incorporating dynamic or heavy 3D/canvas/WebGL libraries into single page applications with multiple routes, always split the route components at the router level using `React.lazy()` to avoid punishing the initial landing page load.
